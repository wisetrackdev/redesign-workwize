🚀 Postman Quick-Start & Testing Instructions

Follow these 3 simple steps in Postman to test any of the QuickFix maintenance APIs:

STEP 1

Generate Bearer Token

Call the POST /api/login API with your username and password. Copy the returned token string from the response JSON.

STEP 2

Set Postman Authorization

In your Postman request, click on the Authorization tab → select Bearer Token → paste the token value into the Token field.

STEP 3

Select Body & Send

Select Body → form-data (or raw JSON where noted). Fill in the parameter keys and values listed below, then click Send!

💡 Base URL for all requests: https://oprofase2.workarya.com
POST https://oprofase2.workarya.com/api/login
